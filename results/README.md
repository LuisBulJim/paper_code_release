# `results/` — outputs of the revised study

Copies of the output folders of `revision_nested_cv/` (the scripts write to `out/`, `r1/results`, `r1/tables`,
`r1/figures`, `ext/results_final`). Weights, pickles and per-image dumps are in the archived release
(`PREDICTIONS.md`). Server paths inside the files were made relative to `revision_nested_cv/`.

## Splits and groups

* `splits.json` — the 3 x 5 nested splits of `nested_cv.py` (seed 42 + repeat; outer test, inner validation
  and train image lists per fold, with the group-aware fold assignment of the final run).
* `groups/groups.csv` — `name,group`: the 28 video groups given to the training run (written by
  `build_groups.py --method idgap --fixed-cut --min-id-gap 30 --max-group-size 15`); `groups_report.csv` adds
  the frame index and index gap per image.
* `groups/nested_groups.csv` — the same partition rebuilt from the splits by `r1/nested_eval.py` (other labels;
  the bootstrap intervals use these).

## `main_study/`

| Path | Content |
|---|---|
| `r1_results/nested_grouped/` | **final protocol.** `per_fold.csv` (every outer fold x model x strategy), `oof_metrics.csv` (out-of-fold, per repeat), `summary.csv` (mean over repeats with cluster-bootstrap 95 % CI), `deltas.csv` (paired differences), `bootstrap.json`, `inference_choice.json` (TTA / WBF chosen on inner validation), `sweep_tta_val*.csv`, `sweep_wbf_val*.csv`, `val_thresholds.csv` |
| `r1_results/nested_ungrouped/` | the same files for the ungrouped run (ablation) |
| `r1_results/nested_summary.csv`, `nested_deltas.csv` | grouped vs. ungrouped side by side |
| `r1_results/failure_cases.csv`, `failure_by_size.csv` | failure analysis of the Medium baseline |
| `r1_results/sam3_*.csv`, `sam3_valthr/`, `sam3_map_r0_m.json` | SAM 3 with the out-of-fold detector on the official LIACI test split (positives / negatives), fold map |
| `r1_results/trashcan*.csv` | TrashCan retraining (3 seeds) and zero-shot OOD of the LIACI models |
| `r1_results/latency.csv` | standard / TTA / WBF latency of the main study, FP32 and FP16 |
| `r1_results/logs/`, `logs_server/` | run logs, `protocol_check.json` (sha256 check of the dataset), `audit_checkpoints.txt` (every checkpoint is YOLO26 and was trained on its own fold workspace) |
| `r1_tables/*.tex`, `numbers.json` | the LaTeX tables of the manuscript generated by `r1/make_tables.py`; `numbers.json` is what `check_consistency.py` checks the text against |
| `r1_figures/*.png` | figures generated by `r1/make_figures.py`, `failure_analysis.py` and `sam3_eval.py metrics` |
| `runs/<tag>_r<r>_f<k>_<size>/` | `args.yaml` and `results.csv` (training curves) of the 90 fold models |
| `trashcan_runs/`, `sam3_runs/` | `args.yaml`, `results.csv`, `run_info.json`, `_meta.json` of the TrashCan and SAM 3 runs |
| `eval_nested_cv/` | the earlier evaluator of `evaluate_cv.py` (image-level bootstrap, truncated-AP "pre" mode) and `bench_latency.py` output; **not used in the manuscript**, kept because `check_consistency.py` reports its numbers as orphans on purpose |
