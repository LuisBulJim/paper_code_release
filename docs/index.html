Abstract

Corrosion detection on submerged hulls is difficult due to poor optical conditions and a lack of annotated underwater images. We evaluated YOLO26 detectors on the public LIACI dataset using repeated nested cross-validation. The outer folds are grouped into runs of neighbouring frames that approximate the source videos. For YOLO26-Medium, the out-of-fold mAP@50 drops from 0.299 with ungrouped folds to 0.167 with grouped folds. A paired analysis attributes most of this drop to test frames whose neighbours were in the training set. The official LIACI split has the same proximity, with 92% of its test frames having an adjacent frame in the training set, which may affect the benchmarks on this dataset. Using the grouped protocol, the Medium and Large models tied; direct and sequential transfer tied for the Medium model; and test-time augmentation added between 0.02 and 0.05 mAP@50 across all configurations. Changes targeting measured failure modes each add a few points. Fusing four models adds between 0.07 and 0.09, regardless of whether the components are variants or unchanged baselines. The recipe selected on validation – an ensemble of four models with test-time augmentation – achieves an mAP@50 of 0.262 at 3.4 images per second.
Revised study. This page and the repository describe the revised manuscript. The first submission evaluated a single split whose test images had also been used to train the cross-validation models; all of its numbers are superseded and its material is kept only under legacy/ in the repository.

Protocol

A video-grouped benchmark for corrosion detection on LIACI, and a measurement of what ungrouped evaluation hides.

  • Repeated nested cross-validation, 3 × 5. Every one of the 261 LIACI corrosion images is an out-of-fold test image once per repeat; inner validation is the only data used for early stopping, checkpoint selection, the TTA / WBF configuration and the operating threshold. YOLO26 Nano / Medium / Large, direct and sequential transfer: 90 fold models.
  • 28 video groups. LIACI does not state which video each frame comes from, so the outer folds are grouped by runs of at most 15 pool images in frame-index order, cut where the index gap exceeds 30. An ungrouped run of the same pipeline is the ablation that measures the leakage.
  • One evaluator. COCO mAP@50 and mAP@[.5:.95], precision / recall / F1 at fixed and validation thresholds, cluster bootstrap over the 28 groups (1,000 replicates), paired differences with Holm correction.
  • Pre-registered improvements on the same splits. Small-data recipe, nine-class training with 1,591 unused LIACI images, segmentation head, copy-paste, their combination, a four-variant WBF ensemble and a control ensemble of four baseline models; pixel-level scoring of masks and boxes; SAM 3 with ground-truth boxes and with text prompts; latency of every recipe; a supplementary check on TrashCan.

Reproducibility

Every table and figure of the manuscript is generated by a script from the released result files.

  • Run code — grouped nested CV (nested_cv.py, build_groups.py), single evaluator and cluster bootstrap (r1/), improvement experiments, pixel and SAM 3 evaluations, latency (ext/).
  • Splits and group assignment — the 3 × 5 outer/inner splits and the 28 video groups used to build them.
  • Results — per-fold and out-of-fold values of every strategy, validation sweeps, bootstrap intervals, latency, SAM 3, pixel IoU, and the generated LaTeX tables and figures.
  • Per-fold predictions and checkpoints — archived release (DOI to be added): all cached TTA views, out-of-fold dumps, SAM 3 masks, 90 + 75 checkpoints.
  • Environment — ultralytics==8.4.5 (hard requirement), torch==2.8.0, ensemble-boxes==1.0.9, pycocotools; SAM 3 via transformers>=5.13 in a separate environment.

Data availability

The code of the grouped cross-validation, the group assignment used to build the folds, the splits, the per-fold out-of-fold predictions and per-fold values of every strategy, the improvement experiments, the region-level and SAM 3 evaluations, the latency benchmark and the scripts that generate every table and figure are available in the repository and in the archived release. The underlying datasets are third-party and publicly accessible from their original sources: the SINTEF LIACI underwater inspection dataset, the TrashCan 1.0 dataset (supplementary check) and an aerial corrosion dataset hosted on Roboflow (sequential-transfer pre-training); the download routines are included in the released code. The trained checkpoints (90 fold models of the main study and 75 of the improvement variants) are deposited in the DOI-referenced archive.
